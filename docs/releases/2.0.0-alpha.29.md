# Justify Lasers 2.0.0-alpha.29

- Fixed bridge attachment gaps; added floor, wall and ceiling mounting with six-direction projection and matching collision.
- Moved schematics into their own creative tab; made raw photonite and wolframite placeable.
- Added flickering light rays inside crystal growers, using the actual mixed input color.
- Moved Silk Touch and Drops slots into Mining settings; added Collect and nine-slot emitter storage, with safe overflow.
- Added Heal, Lift and Lower modules, assembly recipes and schematics; one effect slot selects the entity mode.
- Added searchable mod-aware mob blacklists/whitelists for emitters, world modules and turrets.
- Made placed modules configurable and functional on downstream laser/solar beams. Installed emitter modules take priority; concentrators remain module-free.
- Updated FE costs and charged placed modules from incoming LM. Disabled new Scorch-module insertion while retaining existing items and surface marks.
- Added regression tests, updated English/Russian text and preserved existing inventory slot IDs.
