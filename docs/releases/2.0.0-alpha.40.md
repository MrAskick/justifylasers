# 2.0.0-alpha.40

- Added MagicaVoxel `.vox` import for 16³ models, including palettes and static scene transforms. Imported colors can be replaced with game or mod textures.
- Encoder drafts now survive closing the menu and reloading the world, with local recovery copies for disconnects. Typing E no longer closes text fields.
- Added square/circular brushes from 1 to 16 voxels, palette editing, RGB input and compact Undo/Redo icons.
- Added a rotating encoder hologram with a 2 FE/t power cost.
- Added single-print and continuous modes, start/stop controls and layer-by-layer printing without stretching the model.
- Reworked printer materials using OpenComputers CC0 sprites. Renamed the block to Photopolymer Printer.
- Added the supplied polymer bucket sprite and a dark, slow-flowing liquid with 80% base transparency.
- Made the loot collector smaller than a vanilla chest, replaced its materials and linked its emissive accents to the incoming beam color.

Client and server must update together (network protocol 10). Existing JSON model schematics remain readable.
See the [printing guide](../photopolymer-printing.ru.md) for file limits, materials and recovery behavior.
