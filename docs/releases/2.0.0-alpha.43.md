# 2.0.0-alpha.43

- WorldEdit import now skips unsupported blocks instead of rejecting the whole schematic. This includes missing mod blocks, incompatible states, missing textures, fluids and special block-entity models.
- Skipped positions remain empty; supported blocks keep their textures, UVs and original coordinates in both printing scales.
- Added a skipped-block counter and tooltip in the encoder, with full details in the game log.

Empty results, damaged files and size limits still produce an error without replacing the previous draft. No schematic format or network protocol changes.
