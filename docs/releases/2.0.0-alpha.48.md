# 2.0.0-alpha.48

- Added shared GPU geometry caching for machinery, optics and printed models; moved more light-effect geometry and animation off the CPU. Kept the original detail, textures and gameplay.
- Added a GPU tab to client settings: model/print/effect toggles, a 16–512 MiB geometry budget, upload pacing and current cache usage. Uncached geometry uses the compatibility renderer.
- Fixed false mirror refraction with shader packs and floating sky artifacts caused by Mekanism energy cores entering the shader shadow pass.
- Replaced the JEI printer/encoder preview with the supplied house model.
- Rebalanced advanced crystal production: one bucket of nutrient mixture produces one intermediate crystal, which cuts into 3–6 resources. Six is a 3% outcome. Basic water growth is unchanged.

No new dependencies. [Checks, GPU settings and benchmarks (Russian)](../prompt11-gpu.ru.md).
