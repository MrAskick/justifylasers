# 2.0.0-alpha.31 — Optical balance and inventory integration

- Fixed the Lithium collision crash near hard-light bridges; added 90° roll for upward/downward projections.
- Matched installed and placed Mining LM prices and paid work speed; doubled optical module costs.
- Fixed Heal at 0.1 HP/s and removed strength/frequency settings.
- Added Thickness Module II (8×), native inventory ports, and optional distance loss (disabled by default).
- Raised creative output to 1 Tlm and reduced lava burn duration by three, including already-burning fuel.
- Aligned emitter slots, restyled turret controls, distinguished the Loot Collector, and added a placeable 3D Electric Motor.

Use matching alpha.31 builds on both client and server. Back up the world before upgrading. Registry IDs and inventories are retained; saved creative flux is migrated to the new slider scale (the previous default and maximum retain their output). New attenuation fields are added to existing configs with a `justifylasers.pre-alpha31.json.bak` backup. Servers synchronize attenuation with clients without overwriting their local configuration.

See [beam modules and settings](../beam-modules.ru.md), [bridge orientation](../light-bridge.ru.md) and [verification](../verification.md).
