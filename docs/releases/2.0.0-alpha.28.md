# Justify Lasers 2.0.0-alpha.28

- Fixed stuttering on Hard Light Bridges with Lithium; kept its movement optimizations enabled.
- Slimmed bridge emitters, inset the light surface and matched its collision; fixed missing destruction particles.
- Raised the default bridge range to 256 blocks (configurable up to 512); range still scales with incoming LM and width.
- Made crystal growth proportional to incoming light: 480 klm gives the previous speed. Fractional progress survives saving; no minimum input threshold.
- Replaced growth-chamber electrical arcs with pulsing illumination matching the mixed input color; updated its GUI and JEI reference values.
- Fixed directly touching combiners and optical consumers; preserved per-combiner losses and shared energy budgets.
- Migrated old stock configuration values with a backup; retained custom values and existing content.
