# 2.0.0-alpha.32 — Corner bridges and Configurator

- Added 45° bridge roll and corner emitters for connected hard-light tunnels, with shared LM/color and matching collision.
- Added an animated Configurator radial menu: hold Shift, point at a mode, release to select; Esc cancels.
- Added mode-colored Configurator lighting and a 20,000 FE battery: 20 FE per successful action, free in creative.
- Added charging through the generator, native energy APIs, and the Charge-from-machine mode.
- Rebuilt Thickness Module II as a distinct twin-cartridge amplifier; its 8× upgrade value is unchanged.

Use matching alpha.32 on client and server. Existing bridge mounting/roll, module IDs and tool clipboards are preserved. Old and newly crafted Configurators start uncharged; charge them before survival use. Corner emitters have a tablet schematic and an assembly recipe. Original reference images are not included in the JARs.

See [bridge construction](../light-bridge.ru.md) and the [Configurator guide](../guide.ru.md#configurator).
