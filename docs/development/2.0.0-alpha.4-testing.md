# 2.0.0-alpha.4 verification

Verified locally on 2026-09-10 with Corretto 22.0.2 and Gradle 8.14.3 on Windows. This update changes crystal item presentation, not emitter mechanics.

## Build and regression

`gradlew.bat build --offline --console=plain` passed for all four targets, with 32 JUnit tests and 109 Fabric 1.20.1 GameTests. New tests cover finite, correctly wound 3D geometry, eight solid crown facets, model transforms, all nine color resources, and unchanged crystal recipe requirements.

Forge 1.20.1 / Mekanism 10.4.16.80 and NeoForge 1.21.1 / Mekanism 10.7.19.85 each passed both native integration tests, including cable-powered operation and native save/load. The Forge-only crystal subclass registers its renderer through the client extension hook; dedicated-server initialization also passed.

## Visual checks

- Fabric 1.20.1: all nine inventory models and a resource reload passed the gallery harness (`-PclientSmoke -PsmokeCrystals`). The separate world test passed without shaders.
- Forge 1.20.1: world/network/item checks passed with Oculus 1.8.0, Embeddium 0.3.31, and Kappa_v5.3_Caves.
- Fabric and NeoForge 1.21.1: world/network/item checks passed with Iris 1.8.8, Sodium 0.6.13, and Kappa_v5.3_Caves.

Captures were inspected for inventory colors, metal brackets, pointed geometry, first- and third-person rendering, dropped items, item frames, and shader lighting. The final hand-scale/rotation and continuous-bevel-UV adjustments were rechecked on Minecraft 1.20.1; the common model and renderer compile for both versions. Screenshots remain in each platform's `build/run/clientSmoke/screenshots` directory.

The model uses an opaque, depth-writing world material, including for emissive parts. GUI highlights use a separate opaque unshaded pass. Crystal materials include flat normal maps and emission/specular maps; they do not place Minecraft light blocks. No beam renderer or shader-depth bridge was changed.

## Archives and scope

The four release JARs contain the shared model definition, nine item parents, and all 60 crystal/frame material textures. SHA-256 comparison with the alpha.3 JARs confirmed that all nine crystal recipes are byte-for-byte unchanged. No test harness, Mekanism, or Iris implementation classes are bundled.

Source comparison against `backups/before-crystal-models-2.0.0-alpha.3-20260910-125040/source-2.0.0-alpha.3.zip` confirmed no changes to emitter gameplay, energy costs, saved settings, existing GUI artwork, or beam rendering. That directory also holds the four previous alpha.3 JARs. Reference images and the user's launcher mods/worlds were not modified.

These are isolated development-profile checks. Ordinary release-JAR launcher testing and extended multiplayer/survival testing remain part of the stable-release checklist in [the earlier notes](2.0.0-alpha.3-testing.md).
