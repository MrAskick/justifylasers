# 2.0.0-alpha.44

- Mining lasers can no longer destroy private emitters, machines or their multiblock parts. Protected inventories stay intact. Owners can still dismantle their devices manually.
- Encoder draft uploads now have a cooldown and cannot replace an unfinished upload. Card writes use a separate limit; closing the editor waits for a pending autosave.
- Fixed textures that forced the block atlas to lower or disable mipmaps.
- Reduced repeated work when building light-bridge collision shapes, without changing their geometry.
- Added the missing tablet descriptions for photopolymer, model schematics and printed models in English and Russian. Corrected outdated guide entries about tablet acquisition, creative flux and energy output.

No recipe, balance or save-format changes. This is an unpublished prerelease build; see [verification](../verification.md) for test results and remaining checks.
