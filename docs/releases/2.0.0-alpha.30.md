# 2.0.0-alpha.30

- Fixed falling through light bridges after rejoining and duplicate light charges on combined beams.
- Effects now combine; equal Lift and Descent cancel. Mining shares the Effect slot.
- Added Collection upgrades and nested Mining/Damage upgrade slots. Mining Ignition smelts drops.
- Added a 0–1 Glm creative output slider and rebuilt grower focusing effects.
- Updated EN/RU menus, recipes and tests. Old installed items are retained.

Back up worlds before updating. If an old emitter had both Mining and an entity effect, the entity effect stays active and the old Mining item remains visible for extraction. Collection now requires its module. Solar concentrators still use external beam modules only.
