# 2.0.0-alpha.42

- Added WorldEdit/Sponge `.schem` import to the Model Encoder, with 1:16 miniature and 1:1 full-size printing.
- Printed blocks retain source block states and baked models: per-face textures, UVs, log axes, facing, slabs and ordinary modded block models. Textures come from installed mods and active resource packs.
- Larger builds use multipart schematics and the existing per-part printing and placement system. Full-size slabs retain their collision height.
- The File button accepts `.schem`, `.vox` and model `.json`; drag-and-drop also works. Imports remain asynchronous.
- Added size checks and clear errors for missing blocks, invalid states and unsupported models. Inventories, commands, entities and block functionality are never copied.

WorldEdit is only needed to create/export the source file, not to use the encoder or printer. Legacy numeric-ID `.schematic` files must be re-exported as Sponge `.schem`. Fluids and special block-entity renderers are not imported.

Update both client and server. Forge/NeoForge network protocol: 12.
