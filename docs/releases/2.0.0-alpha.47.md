# 2.0.0-alpha.47

- Moved light bridge animation to the GPU. Bridges reuse cached geometry instead of rebuilding and uploading it every frame.
- Preserved field detail, colors, transparency, edge lighting and shader-pack emission. Collision, range and power consumption are unchanged.
- Bounded the geometry cache and release its GPU buffers on eviction and resource reload. The previous renderer remains available as a fallback when the bridge shader is unavailable.

No new dependencies or world reset required. [Benchmarks and checks (Russian)](../bridge-gpu.ru.md).
