# 2.0.0-alpha.3 verification

Verified locally on 2026-09-10 with Corretto 22.0.2 and Gradle 8.14.3 on Windows. Test commands and isolated-profile setup are in [the general notes](2.0.0-testing.md).

## Build and energy

`gradlew.bat build --offline --console=plain` passed for all four targets, with 29 JUnit tests and 109 Fabric 1.20.1 GameTests.

- Range I and Thickness each add 1 unit/tick per item; Range II adds 8. Tests cover counts 0–64, combined stacks, removal, in-place merges, save/load, menu synchronization, and overflow limits.
- Full Range II and Thickness stacks add 576 units/tick, including the last Range II item at the 512-block cap. A visual-only beam uses 656 with the default base cost.
- Inactive, redstone-blocked, and crystal-less emitters are not charged. Insufficient power prevents activation, and repeated updates cannot charge twice in one world tick. Creative emitters remain free.
- Increased in-place upgrade stacks deactivate the old paid beam until the new cost is paid.

Native integration passed on Fabric 1.20.1 and 1.21.1 without a technical mod (one required test each), Forge 1.20.1 with Mekanism 10.4.16.80, and NeoForge 1.21.1 with Mekanism 10.7.19.85 (two required tests each).

The Mekanism fixture powers a fully upgraded emitter through two Basic Universal Cables, without direct energy injection. The stronger test exposed interference between adjacent GameTest structures: the mining test could destroy the cable test's energy source after breaking its own target. A bedrock stop now contains that test beam. No energy adapter or mining mechanic was changed to address the fixture failure.

## GUI

The supplied `ref/LG_transparent.png` is copied unchanged to `assets/justifylasers/textures/gui/powered_emitter.png`. SHA-256 matches in all four release JARs:

`BD9C22EDA3953BA7611019A8FA3EE60CAF16035938F7682BFD1B977AAADCC794`

The PNG has genuine alpha transparency, not a painted checkerboard. A resource test checks transparent exterior pixels and a partially transparent panel. Minecraft 1.21.1 draws the powered-screen background once; 1.20.1 keeps its required explicit background pass.

World/network smoke checks passed on Forge 1.20.1 with Oculus 1.8.0 / Embeddium 0.3.31 and Fabric 1.21.1 with Iris 1.8.8 / Sodium 0.6.13, both using Kappa_v5.3_Caves. Main/modules captures were visually inspected: world visible through panels, no black exterior, and opaque text, items, and 3D preview. The live menu reports 176 units/tick for eight Range II and 32 Thickness modules, then 185 after adding one of each. Both server and client block entities receive the updated stacks and geometry.

The final world/network checks also passed on Fabric 1.20.1 without shaders and NeoForge 1.21.1 with Iris 1.8.8 / Sodium 0.6.13 / Kappa_v5.3_Caves. Both main-screen captures were visually inspected and show the same transparency and module cost. Screenshots and logs remain under each platform's isolated `build/run/clientSmoke` directory.

The previous eleven-state English/Russian layout checks are recorded in [alpha.2 verification](2.0.0-alpha.2-testing.md); that complete layout matrix was not rerun for alpha.3.

## Artifacts and limits

Four `2.0.0-alpha.3` release JARs are in `build/libs`. Archive checks confirmed the version and original RGBA texture, with no test harness, Mekanism, or Iris implementation classes bundled. Previous JARs remain in place. A pre-edit source snapshot is in `backups/before-module-energy-2.0.0-alpha.3-20260910-121044`.

The user's launcher mods and worlds were not modified. These runtime checks use development profiles; ordinary release-JAR launcher testing, two-client multiplayer, and extended survival testing remain necessary before a stable release.
