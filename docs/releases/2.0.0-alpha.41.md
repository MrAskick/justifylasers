# 2.0.0-alpha.41

- VOX file selection and import now run off the game thread.
- Added a visual color palette and separate color/texture modes in the encoder.
- Large VOX models can be saved as multipart schematics and printed one block at a time, without reducing voxel resolution. Parts keep their coordinates and can snap to matching placed parts.
- Added part selection, an overview and per-part costs to the encoder. Printing resumes at the correct part after a reload.
- Fixed stretched top/bottom printer panels and excessive breaking particles from detailed prints.
- Photopolymer is now 20% transparent.
- Crystal growth yields 0–3 crystals; cutting yields 1–3 usable gems. Grower chances: 15/55/20/10%; cutter chances: 50/35/15%. Seed wear remains, but no longer reduces batch yield.

Update both client and server. Forge/NeoForge network protocol: 11. Minecraft 1.20.1 and 1.21.1 remain separate universal JARs.
