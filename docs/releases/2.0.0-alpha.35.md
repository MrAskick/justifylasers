# 2.0.0-alpha.35

- Fixed overlapping bridge footsteps and centered emitter mounting.
- Added up to 32 live mirrors, optional shader-pack reflections and performance warnings. Updated mirror materials and glow trim.
- Added the Chemical Synthesizer, four nutrient fluids, Spectrum Module, degrading crystal seeds and advanced growth recipes.
- Added the 2×2×2 Laser Cutter with combined LM + FE requirements.
- Preserved early photonite growth; added schematics, JEI details, EN/RU localization and automated coverage.

See the [production guide](../advanced-crystals.ru.md) for recipes, spectra, thresholds and seed yields. Shader reflections are experimental and disabled by default. Back up worlds before upgrading an alpha; clients and servers must use the same build.
