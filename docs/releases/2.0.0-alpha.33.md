# 2.0.0-alpha.33 — Mirrors and placement

- Rebuilt the mirror with independent stand/tilt rotation, color-reactive trim and optional real world reflections: per-frame reflected cameras, depth-dependent parallax and virtual depth compositing.
- Mirror links work without an incoming beam. Hold right-click in Aim mode to rotate a mirror with the mouse while keeping the camera fixed.
- Moved the Configurator wheel to rebindable Left Ctrl.
- Made bridge placement independent of camera pitch, with wall/floor mounting and neighbouring-section orientation copying.
- Removed component-facing requirements from large solar concentrator assembly.
- Reworked chamber and bridge UVs; removed the central roof inserts.
- Added eight randomized hard-light bridge footsteps, turquoise module names and tablet schematic search.

Reflections default to transparent glass. The optional second world view uses vanilla lighting, including with Iris/Oculus enabled; it does not reproduce shader-pack postprocessing or recursive mirrors. Distance and mirror-count limits are adjustable in client settings. Use matching alpha.33 on client and server. Reference sheets and source WAVs are not bundled.
