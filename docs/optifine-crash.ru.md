# Сбой Forge / OptiFine из отчёта message.txt

В предоставленном отчёте использованы Minecraft 1.21.1, Forge 52.1.16, OptiFine 1.21.1 HD U J1 и Justify Lasers alpha.26.

Фатальная ошибка — `NoSuchMethodError: java.util.List net.minecraft.core.Direction.getUpdateOrder()`. Она возникает в обновлении соседних блоков Minecraft/Forge. Вызов из `IndustrialMachineBlockEntity.setChanged` запускает обычное сохранение состояния блока и обновление компараторов; затем движок обращается к отсутствующему методу `Direction`.

На [официальной странице OptiFine](https://optifine.net/downloads?lang=en) для этой версии J1 указана совместимость с Forge **52.0.16**, а не 52.1.16. Наблюдаемое несоответствие методов согласуется с конфликтом заменённых OptiFine классов и более нового Forge. Это обоснованный диагноз по журналу, не результат воспроизведения всей исходной сборки.

Для проверки сначала сделайте копию мира и профиля, затем запустите копию без OptiFine. Текущий Forge-вариант Justify Lasers для 1.21.1 требует Forge **52.1.0+**, поэтому откат до 52.0.16 не является подходящим решением для alpha.33. Для этой версии оставьте OptiFine выключенным либо проверяйте другой поддерживаемый графический стек в отдельном профиле. Альтернативные проверенные связки перечислены в [отчёте проверок](verification.md). Не меняйте загрузчик прямо в рабочем профиле: другие моды и данные мира могут быть несовместимы.

В alpha.33 не добавляется перехват этой ошибки: подавление обновлений соседей скрыло бы несовместимость ценой нарушенной работы редстоуна и сохранения машин. Полная совместимость вторичного рендера зеркал с OptiFine не заявляется. Файлы установленной игры при разработке не изменялись.
