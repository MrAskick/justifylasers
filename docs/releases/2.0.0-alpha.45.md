# 2.0.0-alpha.45

- Cached printed-model geometry, UVs and normals instead of rebuilding them every frame, including item previews, holograms and mirror views. Resource reloads rebuild the cache.
- Removed duplicate vertex submissions for printed quads and repeated material lookups within the same render layer.
- Precomputed static optical-machine geometry and switched it to complete-vertex submission, keeping dynamic lighting, glow and glass.
- Cached mirror collision shapes. Turning or remounting a mirror invalidates them; ordinary beam tracing no longer rebuilds them every tick.

No changes to recipes, balance, model detail, render distance, reflection settings or save formats.
