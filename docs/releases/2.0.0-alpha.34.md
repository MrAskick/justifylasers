# 2.0.0-alpha.34 — World-entry hotfix

- Fixed the Forge 1.21.1 freeze at "Loading terrain...", including when mirror reflections were disabled.
- Restore the original main-camera culling frustum after rendering reflections; use the separate, unclipped culling projection for mirror views.
- Added a native-client regression check that verifies the main frustum on every world frame.

No gameplay, registry or save-format changes. Replace alpha.33 with alpha.34; do not install both JARs. Existing mirror settings and reflected depth are retained. Use matching versions on client and server.
