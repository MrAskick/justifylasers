# 2.0.0-alpha.37

Changes since **2.0.0-alpha.26**.

- Added Hard Light Bridges with connected widths, corner emitters, 45° rotation and light tunnels; fixed collision, rejoining and unpitched footsteps.
- Added composable beam effects, target lists, world-module settings, nested Mining upgrades, collection storage and automation. Rebalanced LM costs and lava fuel; added optional beam attenuation.
- Added Thickness II, 15 amplifier tiers (+1 lm to +1 Tlm), JEI upgrades and 1 Tlm creative output.
- Added the Chemical Synthesizer, nutrient fluids, Spectrum Module and Laser Cutter; hue-based growth, gem wear/origin tags and saved paused progress.
- Added live mirror depth/parallax, aiming and optional shader reflections; fixed Forge world-entry freezes, Lithium crashes, adjacent combiners and port copying.
- Added the rechargeable Configurator wheel, tablet search, schematic tab, placeable minerals and 3D motor. Updated models, GUIs, display settings and EN/RU text (“Waiting for fluid”).
- Removed growth presets and new Scorch-slot insertion; preserved scorch marks and legacy migration. Removed local authoring tools from the repository.

Install **one universal JAR** matching Minecraft 1.20.1 or 1.21.1; Fabric still requires Fabric API. Back up worlds and update clients/servers together. Shader reflections remain experimental and off by default. Artificial-origin item data is not a complete anti-exploit system; see the [production guide](https://github.com/MrAskick/justifylasers/blob/v2.0.0-alpha.37/docs/advanced-crystals.ru.md).
