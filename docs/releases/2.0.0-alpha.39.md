# 2.0.0-alpha.39

- Added a 2×2×2 photopolymer printer powered by FE, violet laser light and liquid resin.
- Added a model encoder with Blockbench Java Block/Item JSON import, a layer-based voxel editor, mod/resource-pack texture search and a rotatable preview.
- Added reusable model schematics and placeable printed models with saved geometry, UVs, textures and voxel collision.
- Added photopolymer synthesis, machine assembly plans, JEI examples/construction help, and English/Russian localization.
- Printing time, resin, FE and required optical flux scale with volume and detail. Interrupted jobs retain their progress; changing the schematic cannot transfer paid work.

Format limits and operating instructions: [3D printing guide](../photopolymer-printing.ru.md).
