# 2.0.0-alpha.49

Changes since alpha.37:

- Added the Photopolymer Printer and Model Encoder: voxel editing, game/mod textures, and Blockbench JSON, MagicaVoxel VOX and WorldEdit `.schem` imports.
- Added multipart printing for large models, saved editor drafts and resumable print jobs. Unsupported schematic blocks are skipped.
- Optimized bridges, machinery, printed models and effects with GPU caching. Added GPU memory and performance settings.
- Reworked crystal seeds, growth/cutting yields, crystal recoloring and amplifier stacking. Amplifier tiers V–VI are temporarily hidden.
- Added a searchable tablet guide, reusable/erasable schematics and expanded JEI support.
- Fixed bridge alignment and collision performance, printed-model rendering, shader artifacts and mirror flickering/depth.
- Fixed inventory automation and laser mining protection; refreshed machine and module textures.

Prerelease. Back up worlds and update both client and server. Universal builds are provided for Minecraft 1.20.1 and 1.21.1.
