# 2.0.0-alpha.36

- Added 15 amplifier tiers, a dedicated emitter slot and JEI upgrade recipes; output scales from +1 lm to +1 Tlm with increased FE consumption.
- Replaced exact growth-color presets with hue ranges. Paused growth now retains progress and spent fluid.
- Moved seed wear into gem data, added probabilistic degradation and revised yields. Artificially cut gems keep vanilla IDs but cannot seed growth.
- Fixed Configurator port copying for splitters and combiners; adjusted bridge walking and sprinting sounds.
- Added a client toggle for machine displays. Updated nutrient fluids, bucket textures, placeable translucent grown crystals, Spectrum Module geometry/materials and Laser Cutter materials.
- Removed growth preset buttons and the redundant seed label. Legacy seed IDs remain hidden for save migration.

See the [production guide](../advanced-crystals.ru.md) for hue ranges, probabilities and amplifier costs, and [verification](../verification.md) for tested configurations. Back up worlds before upgrading; update clients and servers together.
