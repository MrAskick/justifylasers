# 2.0.0-alpha.46

- Fixed the black in-block overlay near printed models and kept collision tied to their actual geometry.
- Fixed light bridge emitter culling near screen edges, reduced excessive break particles, and added automatic aperture alignment between straight and corner emitters. Sneak placement and manual 45° rotation remain available.
- Optimized bridge vertex generation without reducing field detail, animation or render distance.
- Rebalanced advanced crystal cultivation: 250 mB of nutrient per cycle, with 1/2/3 grown crystals at 20/55/25%. Basic growth, seed wear, light requirements and cutting costs are unchanged.
- Replaced mounted seed models with pointed crystal clusters that show wear. Renamed seeds to «Ростовое ядро» in Russian.
- Reworked Mining Module materials with pixel-art panels, separate UV regions and stronger illuminated strips.
- Mounting photonite now produces a magenta laser crystal. The Chemical Synthesizer recolors any laser crystal using water and the corresponding mineral reagent; workbench dye recipes were removed.
- Moved the Spectrum Module to the crafting table: eight colored crystals around a Control Circuit. Removed its assembly recipe and tablet entry; existing schematic items remain loadable and erasable.
- Photopolymer now uses photonite instead of amethyst. Fixed fluid names, including Forge/NeoForge fluid types used by other mods. Empty machine tanks now show a generic fluid label.

Update clients and servers together. No world reset is required.
