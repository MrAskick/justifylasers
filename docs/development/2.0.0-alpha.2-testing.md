# 2.0.0-alpha.2 verification

Verified locally on 2026-09-10 with Corretto 22.0.2, Gradle 8.14.3, Windows 11, and an RTX 5090. Commands and disposable-profile setup are described in [the general test notes](2.0.0-testing.md).

## Build and regression

`gradlew.bat build --offline --console=plain` passed for all four targets.

- 27 JUnit tests passed, including localization-key parity, new item models/recipes, technical recipe conditions, range-II crafting, and stable module slot IDs.
- 107 Fabric 1.20.1 GameTests passed. New checks cover every upgrade stack count, tier separation, shift-click remainders, missing capability modules, redstone gating before energy consumption, owner/access persistence, legacy five-slot saves, private menu/packet/automation restrictions, and increasing energy costs.
- In-place upgrade merges invalidate the cached beam path immediately. The Forge client/server scene also verifies that changed counts reach both the client block entity and menu, not just server getters.
- SHA-256 comparison against the pre-edit source backup confirmed 25 existing world-renderer, optics/gameplay, compatibility, and original-screen files are unchanged. This is a source comparison, not a substitute for runtime regression tests.

## Clients and shaders

World/network smoke checks passed on all four targets. Fabric 1.20.1 was rechecked without shaders for this update. Forge used Oculus 1.8.0 / Embeddium 0.3.31, and both 1.21.1 targets used Iris 1.8.8 / Sodium 0.6.13, with Kappa_v5.3_Caves. The earlier alpha.1 Fabric 1.20.1 Iris combination remains documented separately; it was not rerun here.

Captures were inspected for the real 3D emitter/color preview, white beam core, halo, scorch effects, and occlusion. The real menu test checks owner privileges, inventory and energy properties, a damage-setting round trip, stale packet rejection, and rejection of manual range settings on the powered emitter.

The layout harness passed on all four targets, capturing eleven pages/states in English and Russian, including an 854×480 window. It checks control bounds/overlap and all 36 player slots across subpages. Main, modules, damage, security, and redstone compact captures were visually inspected. Screenshots and logs remain under each platform's isolated `build/run/clientSmoke` directory.

## Release contents

All four distributable JARs are collected under `build/libs` with version `2.0.0-alpha.2`. Archive checks confirmed the powered GUI texture/classes, security mixin registration, and 20 powered-emitter/part recipes in the version-appropriate resource directories. Minecraft 1.20.1 class files target Java 17; 1.21.1 class files target Java 21. No test harness, Mekanism, or Iris implementation classes are bundled.

The pre-edit source and four alpha.1 JARs are backed up under `backups/before-powered-gui-2.0.0-alpha.1-20260910-053839`. Older files in `build/libs` were not removed. The user's launcher installation, mods, and worlds were not modified.

## Still required before a stable release

- Run the remapped release JARs in ordinary launcher profiles. Automated clients here use Loom's development classpath.
- Test a dedicated multiplayer session with two real clients, reconnects, chunk unload/reload, and extended survival use.
- Test other energy mods individually before calling them verified integrations.
- Back up worlds before upgrading. Alpha.1 powered emitters keep their original parts and energy but now require the new capability/range/thickness modules; empty upgrade slots intentionally use the new minima.
